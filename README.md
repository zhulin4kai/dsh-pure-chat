# DSH-对话区

在 DSH 侧边栏顶部提供一个和工作区并列的「对话区」：搜索、筛选、新建对话，以及每个对话独立的人格。

## 功能

- 独立的「对话区」分区，位于「工作区」上方。
- 搜索对话、按最近更新/最早更新/名称排序、新建对话。
- 每个对话通过「...」菜单编辑人格、重命名、归档、删除。
- 人格按会话保存，只影响当前对话；默认人格不写入 AGENTS.md。
- 纯对话不绑定工作区，只保留联网工具。

## 目录

```text
dsh-plugin-pure-chat/   Host + Client 单 bundle
```

## 安装

### 通过 npm

在 DSH 的「插件」→「添加插件」中输入包名：

```text
dsh-plugin-pure-chat
```

> npm 包尚未发布时，请使用下面的 GitHub 或本地目录安装。

### 通过 GitHub

在「添加插件」中输入仓库地址：

```text
https://github.com/zhulin4kai/dsh-pure-chat
```

### 本地目录

```bash
git clone https://github.com/zhulin4kai/dsh-pure-chat.git
```

然后在「添加插件」中填写仓库根目录的绝对路径。

安装后重新加载页面。

## 使用

- 点击「对话区」右侧的加号新建对话。
- 点击会话行的「...」编辑人格或管理对话。
- 人设在下一轮请求生效，不会插入对话消息。

## 实现说明

- Host 注册 `chat` Agent preset，并持久化每个会话的人格。
- Client 在原生侧边栏工作区浏览器前插入「对话区」，并过滤原生「未分组」重复项。
- 会话排序读取消息树插件提供的整棵树稳定时间；未安装消息树时使用会话自身的 `updatedAt`。

## 已知限制

- 「对话区」使用自绘行和菜单，不是原生工作区组件的一比一行为复刻。
- 隐藏原生「未分组」依赖 DSH 当前侧边栏的 DOM 类名，升级后可能需要适配。
- 当前没有置顶、分叉、复制 Session ID 或拖拽排序。
